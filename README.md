# 📚 Islamic Maghreb & Al-Andalus History Website  
# 📚 موقع تاريخ المغرب الإسلامي والأندلس

---

## 🌍 English

A web platform dedicated to presenting the rich history of the Islamic Maghreb and Al-Andalus in a modern and interactive way.

### ✨ Features
- 🏛️ Historical topics and articles  
- 📅 "On This Day" events  
- 🔍 Search system  
- 🤖 Interactive chatbot (Al-Wajeeh)  
- 📱 Fully responsive design  

### 🛠️ Technologies
- PHP  
- MySQL  
- HTML5 / CSS3  
- JavaScript  

### 🎯 Goal
To make the history of the Islamic Maghreb and Al-Andalus accessible and engaging using modern web technologies.
